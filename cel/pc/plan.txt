#   bewust gestopt met --stop -> blijft staan  ·  GPU werkt (nog) niet -> wacht, volgende start opnieuw

# Verdeling van de Threadripper (64 kernen = 128 threads) als alles tegelijk draait:
#   oersoep_groot (GPU): 2 threads (aansturing van de GPU + snapshots), elke 2 uur 8 analyseprocessen;
#   leven_scan (CPU): 54 jobs x 2 threads = 108 (analyses van klare jobs gebruiken dezelfde plekken);
#   samen hooguit ~118 van 128: ruimte over voor Windows/WSL, Claude en de status.  Niets overboekt.


# 1. oersoep_groot — de grote proef op de GPU.  Een willekeurige soep van 512 x 512 (786.000 deeltjes,
#    26x de testdoos van L = 100), chemie aan, 50 miljoen stappen.  Duur: geschat een halve dag tot 3 dagen (de
#    snelheid op de RTX 8000 is nog nooit gemeten; setup meet hem).  Elke 2 uur analyse + beelden in
#    cel/beelden/oersoep_groot/.  Snapshot elke 10.000 stappen (~8 MB); longrun.py dunt oude snapshots
#    uit (rond elke deling blijft alles) en houdt hooguit 50 GB aan snapshots.
#    Alleen op de GPU (--engine gpu): werkt die niet, dan wacht deze regel; op de CPU zou dit weken
#    duren en de sweep verdringen.
#    Instellingen: als engine/params/production.ini er is (de afgestemde chemie van de levensfase), die.
#    Anders de membraanfysica van membranes.ini met een VOORZICHTIGE GOK voor de chemie (niet
#    afgestemd!): synthese traag ten opzichte van de instroom van voedsel door de wand (team A: met
#    p_syn_a 2e-4 liepen de lumens al leeg), dus p_syn_a 3e-5 en p_syn_b 1e-4 (snelle variant ~3x);
#    langzame vervanging en verval; voedsel ontstaat gelijkmatig overal (W -> N) tot hooguit 12 % N
#    (te veel losse N lost blaasjes op).  Niet roeren: dat test leven_scan eerst.
als engine/params/production.ini bestaat: \
  longrun.py oersoep_groot --engine gpu --ini engine/params/production.ini \
    --set init=soup L=512 steps=50000000 snap_every=10000 stats_every=1000 log_every=10000 ckpt_every=200000 \
    --max-snap-gb 50
anders: \
  longrun.py oersoep_groot --engine gpu --ini engine/params/membranes.ini \
    --set init=soup L=512 steps=50000000 snap_every=10000 stats_every=1000 log_every=10000 ckpt_every=200000 \
          chem=1 events=1 p_syn_a=3e-5 p_syn_b=1e-4 p_rep_a=1e-5 p_rep_b=1e-5 mu=0.02 \
          p_ld=2e-6 p_kd=5e-6 p_nd=1e-6 feed=uniform p_feed=1e-4 feed_cap=0.12 \
    --max-snap-gb 50
