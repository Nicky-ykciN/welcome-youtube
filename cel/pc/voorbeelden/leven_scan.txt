# leven_scan — brede verkenning van de levensfase (stap 2 van de ladder: eten, groeien, delen).
#
# Basis: de beste membraanfysica (engine/params/membranes.ini: 9-14 gesloten blaasjes met enzymen per
# doos van L = 100, chemie uit) met de chemie AAN.  Alles begint als een willekeurige soep (SPEC §0).
# Gedraaid over de knoppen die notes/literatuur_deling.md noemt (route 2: oppervlak groeit sneller dan
# inhoud, plus zacht roeren):
#   p_syn_a   hoe snel een enzym 4 voedseldeeltjes (N) omzet in een nieuw lipide.  Team A zag dat de
#             lumens leeglopen als de synthese sneller is dan de instroom van N door de wand (al bij
#             2e-4), dus trager: 1e-5 .. 1e-4.  De snelle variant Kb (ontstaat alleen door mutatie)
#             is steeds ~3x sneller.
#   a_T_N     afstoting staart-voedsel = hoe slecht N door de wand komt (120 = membranes.ini; lager is
#             doorlaatbaarder; onder ~60 vormen zich geen blaasjes meer, team B).
#   feed_cap  hoeveel N er hoogstens in de hele doos is (begin: 0.10).  Voeding is overal gelijk
#             (W -> N, kent geen cellen); te veel losse N (0.20) lost blaasjes op (team A).
#   stir_A    zacht, gelijkmatig roeren (Kolmogorov-stroming op álle deeltjes).  1e-3 vernielt
#             blaasjes (team B), dus 0, 1e-4 en 3e-4.
# Langzaam: vervanging van enzymen (p_rep), verval van lipiden/enzymen/voedsel (p_ld, p_kd, p_nd).
#
# 3 x 3 x 2 x 3 = 54 varianten x 2 soepen = 108 jobs van 2 miljoen stappen (delingscycli duren in
# zulke simulaties 10^5-10^6 stappen).  Met --threads 2 --reserve 20 draaien er op de Threadripper
# (128 threads) 54 tegelijk = 2 rondes; geschat 3-5 uur in totaal (op deze ontwikkelmachine:
# 1,3 ms/stap met 2 threads; de echte snelheid moet op de pc blijken).
# Schijf: snapshot elke 10.000 stappen (0,3 MB) -> ~7 GB voor de hele sweep.
#   python3 cel/pc/sweep.py cel/pc/voorbeelden/leven_scan.txt --threads 2 --reserve 20 --achtergrond
# (start.sh doet dit vanzelf via cel/pc/plan.txt.)  Ranglijst: cel/runs/leven_scan/SAMENVATTING.md
naam  = leven_scan

zet   = p_rep_a=1e-5 p_rep_b=1e-5 mu=0.02 p_ld=2e-6 p_kd=5e-6 p_nd=1e-6 feed=uniform p_feed=1e-4
raster a_T_N    = 120 90 70
raster feed_cap = 0.11 0.13
raster stir_A   = 0 1e-4 3e-4
